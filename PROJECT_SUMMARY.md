## 📞 Support

### Troubleshooting
1. Check relevant .md file (README, DEPLOYMENT, etc.)
2. Look at browser console (F12)
3. Try clearing cache and localStorage
4. Test in incognito mode
5. Try different browser

### Common Issues
- **Admin won't login**: Clear localStorage
- **Data not saving**: Check storage quota
- **Images not loading**: Verify file path
- **Performance slow**: Optimize images
- **Not indexed by Google**: Submit sitemap
